NovaCloud Console

Terminal

Run authenticated NovaCloud control-plane commands from a guarded browser console.

Appwrite session required
novacloud@console

Execution model

  • Uses the active Appwrite browser session with `credentials: include`.
  • Maps commands to NovaCloud API Gateway routes under `/api/v1/*`.
  • Blocks unknown commands client-side before network execution.
  • Designed for read-first operations; mutations can be added behind RBAC scopes.
